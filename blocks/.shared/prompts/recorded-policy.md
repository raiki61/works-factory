## Recorded policy

Recorded policy is the rules that a person or the owner of the target left on record as "decided". Its sources are only the four below (the copy of the policy document, the answers of the request, the answers a person gave at approval nodes, and the settled points that the check of the decision records raised), plus the recommendations that an unattended run took at an approval node or at a question the judgment held (not a person's decision, but conditions this run took to follow). Code comments, docstrings, and test descriptions in the target repository are "the target's text" unless they hit a row below: a description of how the code is now, not the owner's decision. When the target's text disagrees with the clean form, do not make it a conflict with the policy; rewrite that text as part of the fix. When you say something conflicts with the policy, copy the naming of a row below exactly as it is written (the machine checks that it hits the list, and rejects it if it does not).
