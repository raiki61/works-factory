### 3.4 起こし方

工場の clone の根から `uv run --isolated python3 viewer/flowview.py --target <対象のリポジトリ> [--run <run の id>] <出力の html>`。

- `uv run --isolated` は根の `pyproject.toml` の宣言（PyYAML）を入れて走らせる（試験の命令と同じ形。E3・`outside-packages-ok`）。外のパッケージは足さない（`sqlite3` は標準）。
- `--run` が無ければ、その run の家の一番新しい親の run（`parent_run_id` が空）を見る。`--target` も `--run` も無ければ、今の木の作りの図だけを出す。
- `--target` が在れば、どの run を見ても、ページに run の一覧（3.5）を入れる。

### 3.5 run の一覧とログ（問い 3 の答え）

- run の一覧: その run の家の親の run の全部を、1 行ずつ出す。行は id の頭 8 字・グラフの名・状態（走り中・止まっている承認ノードの名・終わり・落ち）・始めの時刻・かかった時間・費用・落ちた時は誤りの頭の 1 行。並びは新しい順。読むのは `archon.db` の run の行だけで、ログは読まない（`runread.py` の 1 か所）。
- 一覧の行から別の run を見る形: 1 枚のページなので、ページの中で別のファイルへ移れない（持ち主の見方。VS Code の HTML のビューア）。一覧の行は、その run のページを作る命令の 1 行（`--run <id>`）を写せる形で出す。全部の run の再生をページに埋める形（代案）は、run 1 つで会話の中身を含むので、run の数だけページが太る。部署が決めた（見た目は「みながらまたブラッシュアップしましょう」なので、使ってみて変えてよい）。

## 4 外の道具 elkjs と外のパッケージ

- 案 E1（推し）: リポジトリに入れない。`viewer/elkjs.json` に包みの名・版・npm の登録所の tarball の照らしの値（`integrity` の sha512）を止め、初めて使う時に `lib/webget.py` で取り、`${XDG_CACHE_HOME:-~/.cache}/works-factory/viewer/elkjs-<版>/` に tarball の形のまま（`package/lib/elk.bundled.js`・`package/LICENSE.md`）置く。照らしが合わなければ止める。ページには、埋める直前に「elkjs <版>・EPL-2.0・取った所」の注を置き、bundle の頭の license の注は消さない。

  - 代償: 初めての 1 回は網が要る。網が無ければ、置くべきパスと照らしの値を出して止める。
- 案 E2: `viewer/vendor/elkjs/<版>/` に写して入れる（`lib/borrow/` と `borrow.json` の形）。網が要らない。代償は上の訳の裏。
