行の欄: 元（今の works の file:line と関数）・今（works-factory の住処か「無し」）・証（外すと赤になる試験、か「要追加: <試験の名> — <何を照らすか>」）・本物の run（本物の run の記録のどこで見えるか、か「筋書きでのみ」）・狭め（無し、か狭めた PR と「Archon で不可（源の行）」か「不可でない → 戻す」）。

穴の数え方（tail.md の各領域の終わりの「数」と、末尾の「穴の要約」の数）: 行の欄だけから今の値を数える。後の PR が行を閉じたら、その PR が行の欄と数を一緒に直す。
- 今: 無し: 「今」の欄が「無し」で始まる行。
- 証が要追加か弱い: 「証」の欄が「要追加」で始まるか、欄に「弱い:」が在る行。前の証として残した文の中の「要追加」は数えない。
- 狭めたのに Archon が強いていない: 「狭め」の欄の能力が今も狭まったままの行。持ち主が戻さないと決めた行も数える。数えないのは、「無し」の行・Archon で不可（源の行）の行・戻した（「→ … 戻した」か「→ … 戻っていた」の形）行・置き換えか能力を残す決めで能力が残る行・ほかの行の能力に結ぶだけの行・設計の順で後の段に置いた行。
各領域の数は「- <名>: <数>（<行 ID>・<行 ID>…）」と行 ID を並べて書き、穴の要約は各領域の数を「（T <数>・E <数>・R <数>・M <数>）」で足す。今と証の並びが欄から数えた行と合うこと、数が並びの長さと合うこと、穴の要約が各領域の数の足し算であることは tests/layers/test_capability_pointers.py が照らす。狭めの並びは欄を読んで人が選ぶ。戻したと書く狭めがこの形であること（一部だけ戻した行は名を挙げて外す）と、戻した行の ID が docs/nodes.json の gaps と tests/e2e/evidence.json の why に残らないことは tests/layers/test_restored_not_gaps.py が照らす。

指しの形: 「今」は `path::名`（名は最上位の関数・クラス・定数か `クラス.名`。YAML は `path::節の id`）、「証」は `path::Class.test_name`。パスはリポジトリの根から毎回書き、行番号は書かない（試験や関数を 1 つ足すたびに関係の無い行までずれる）。名とパスが main に在ること、「今」「証」に行番号もこの形から外れた指しも無いことは tests/layers/test_capability_pointers.py が照らす。「要追加」から文の終わり（「。」か行の終わり）までの名は、まだ無い名なので照らさない（今在る名は「。」の後に書く）。「元」は版を止めた今の works の file:line のまま。各ファイルの末尾の「穴の要約」は、持ち主に上げた物と、書いた時点の数（tail.md の数だけは上の「穴の数え方」で今の値）。持ち主に上げた物の行き先は線の配線の文書の「この文書の外」が正。
