## Departures from the judgment's prescription

The section "The judgment's prescriptions and the plan's answers" of the material file lists each unit whose prescription (the way to fix that the judgment gave for the unit) an item of the plan does not take: each row starts with the unit key between backquotes, then the prescription, then how the plan answered it: `follows (item <i>)`, or `departs (item <i>)` with the plan role's reason. The judgment's prescription is what the person who asked for the fix can only overrule at the approval node, so a plan that leaves it is never let through quietly, however well the plan role explains the departure: every departure is asked of a person at the approval node before the fix starts, and you, a different eye from the plan role (the AI that wrote the plan), write the recommendation. For every departure in that section, write one row in the root field `prescription_departs`: `{item: <the number of the item that departs>, prescription: "<the unit key, exactly as written between the backquotes, without them>", why: <why you recommend this answer>, recommend: {recommend_shape}}`. Recommend continue when the plan's reason holds and the plan should go on as it is, and stop when the fix should take the judgment's prescription instead. Write one row per pair of item and unit key. Rows you wrote in an earlier pass are kept: write a row only for a departure that has none yet, or to change a recommendation. The acceptance check rejects a departure with no row in this pass or an earlier one, and a row that points at no departure. `why` and the `note` and `why` of `recommend` are shown at the approval node (the point before the fix where a person answers each item) as they are: write them for a reader who knows neither the run nor the factory (do not write <path>:<line> or <field>[<n>]).
