## Departures from the judgment's prescription

The section "Deviations recorded in the plan" of the material file lists the rows where an item of the plan does not take the prescription the judgment gave for a unit (a row shown as `prescription <unit key>` that departs, with the plan role's reason). The judgment's prescription is what the person who asked for the fix can only overrule at the approval node, so a plan that leaves it is never let through quietly, however well the plan role explains the departure: every departure is asked of a person at the approval node before the fix starts, and you, a different eye from the plan role (the AI that wrote the plan), write the recommendation. For every such departure, write one row in the root field `prescription_departs`: `{item: <the number of the item that departs>, prescription: "<the unit key the row names>", why: <why you recommend this answer>, recommend: {recommend_shape}}`. Recommend continue when the plan's reason holds and the plan should go on as it is, and stop when the fix should take the judgment's prescription instead. Write one row per pair of item and unit key. Rows you wrote in an earlier pass are kept: write a row only for a departure that has none yet, or to change a recommendation. The acceptance check rejects a departure with no row in this pass or an earlier one, and a row that points at no departure. `why` and the `note` and `why` of `recommend` are shown at the approval node (the point before the fix where a person answers each item) as they are: write them for a reader who knows neither the run nor the factory (do not write <path>:<line> or <field>[<n>]).
