## Recorded policy

Recorded policy is the rules a person or the target's owner recorded as "decided". It comes only from the four sources below (the copy of the policy document, the request's answers, people's answers at the approval nodes, and the settled points an earlier check listed), plus the pushes an unattended run took at an approval node or for a held question of the judgment (not a person's decision, but conditions this run chose to follow). Comments, docstrings, and test descriptions in the target repository's code are "the target's text" unless a row below covers them: a description of the code as it is now, not the owner's decision. If the target's text disagrees with the clean form, do not call it a conflict with the policy; the fix rewrites that text as part of the change. When you say something conflicts with the policy, copy the name of a row below exactly as written (the machine checks that it matches the list, and rejects it if it does not).
