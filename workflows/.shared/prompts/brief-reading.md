How to read a brief file (the file the machine writes for one item of the fix plan; it is the source of the requirement):

- The section "背景" (background) is reference only. If it disagrees with the brief, the brief wins. If you see the brief itself as wrong, do not reinterpret it: raise it as the instructions say (a conflict declaration in a fix, an objection in a plan).
- If a `rewrite_tests` row's `limit` says it could not be looked up ("引けない"), that rewrite is not allowed.
- If the scope sections say the plan did not decide a scope ("この案は範囲を決めていない"), the scope does not bind this item.
