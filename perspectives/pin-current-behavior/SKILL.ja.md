# 今の振る舞いをテストで留める

**芯の決まり: コードを変えない。今のままの振る舞いを保つテストを足し、どのテストも変化を捕まえると示す。**

## 落とし穴（先に読む）

- **コードを変えない。** 欠陥は「振る舞いを捕まえるテストが無い」ことで、直しはテスト。変える前の版に在る設定のファイルも書き換えない。
- **足したテストはどれも、変える前の版で通る。** 通らないなら、今のコードが誤りかもしれない: テストを曲げて通さず、コードも直さない。「留めるテストが今の版で落ちる」と申し出て、テストの方が正しいと見るか、どちらが正しいか分からないかを書き、その欠陥は直さずに置く。
- **揺れる出力を入れない。** 留めるテストは古い版で 2 回以上回る。回すたびに違う物（時刻・順序・乱数・一時の置き場のパス）があると壊れる。揺れない物だけを留める。
- **一度も赤にならないテストは何も示さない。** どんなコードでも通るテストは留めにならない。

## 留め方

1. 留める振る舞いごとに、本物の呼び手が使う道を通って、コードが今することを確かめるテストを書く。
2. 変える前の版で回す: 通る。もう 1 回回す: まだ通る。
3. **縛っていると示す。** テストが縛るはずのコードを壊し、テストが赤になるのを見る。コードを戻し、緑になるのを見る。足したテスト全部でやり、テストごとに（テストの id と、赤を見たこと）残す。
4. コードを変えていないので、指す直した行の範囲は無い。証拠はテストごとの赤→緑。

## しないこと

- 在るテストを緩めない・消さない。
- 赤→緑の示しが裏付けないテストを足さない。
