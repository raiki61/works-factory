# 振る舞いを変えずに片付ける

**芯の決まり: 振る舞いは前と後で同じ。変える前に通ったテストは、変えた後も全部通る。**

## 落とし穴（先に読む）

- **ここではテストが約束。片付けを通すためにテストを触らない。** はっきり許された物の外の在るテストを変えない。テストが消えてよいのは、それが縛る物そのものを消す時だけ。
- **「何も呼んでいない」は思い込まず確かめる。** 消す前に、呼び手と参照を全部検索する。公開の API はリポジトリの外に届く: リポジトリの中に呼び手が残らないことは、外に残らないことを示さない。
- **振る舞いを変えないと済まない片付けは、片付けではない。** 閉じるのに何かのすることを変える要があるなら、止めて、振る舞いの変更として扱う。

## 片付ける物

- 変更で要らなくなったコードと抽象。
- 最後の呼び手や参照を失った引数・変数・関数・export・import・型。
- どの呼び手も今は同じ値を入れる引数やオプション: 定義に畳んで消す。ただし畳むと変えてはいけないテストを変えることになるなら、残す。
- 行き止まりの道（何も呼ばず何も届かない入口や設定）: 消すか、呼び手をつなぐ。注を書いて済ませない。

## 何も変えていないと示す

変更が届くテストを、テストの道具自身の選び方で絞って回し、前に緑だった物が後でも全部緑だと見る。消した物をまだ述べている文は書き直す。
