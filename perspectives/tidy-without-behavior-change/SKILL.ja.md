# 振る舞いを変えずに片付ける

**芯の決まり: 振る舞いは前と後で同じ。変える前に通ったテストは、変えた後も全部通る。**

## 落とし穴（先に読む）

- **ここではテストが約束。片付けを通すためにテストを触らない。** はっきり許された物の外の在るテストを変えない。テストが消えてよいのは、それが縛る物そのものを消す時だけ。
- **「何も呼んでいない」は思い込まず確かめる。** 消す前に、呼び手と参照を全部検索する。公開の API はリポジトリの外に届く: リポジトリの中に呼び手が残らないことは、外に残らないことを示さない。

## 手順

### 片付ける物

- 変更で要らなくなったコードと抽象。
- 最後の呼び手や参照を失った引数・変数・関数・export・import・型。
- どの呼び手も今は同じ値を入れる引数やオプション: 定義に畳んで消す。ただし畳むと変えてはいけないテストを変えることになるなら、残す。
- 行き止まりの道（何も呼ばず何も届かない入口や設定）: 消すか、呼び手をつなぐ。注を書いて済ませない。

### 何も変えていないと示す

変更が届くテストを、テストの道具自身の選び方で絞って回し、前に緑だった物が後でも全部緑だと見る。絞る手段（id や名でテストを選ぶ手段）がプロジェクトに無い時だけ、答える直前に全部を 1 回回す。消した物をまだ述べている文は書き直す。

## 済んだと言える時

- 変える前に緑だったテストが、変えた後も全部緑。
- 許された物の外の在るテストを変えておらず、テストが消えたのは縛る物と一緒の時だけ。
- どの消しも、呼び手と参照の検索に基づく（公開の API の手前まで）。
- 消した物をまだ述べている文が無い。

## 返し方

消した物・畳んだ物と、何も呼んでいないと示した検索。回したテストと、前に緑の物が後でも全部緑であること。消えたテストと、それが縛っていた物。書き直した文。

## 例

入力: ある変更の後、書式のオプションを、どの呼び手も同じ値で入れている。

返し:

- オプションを検索した: 呼び手は 4 つで、どれも同じ値を渡す。公開の API ではない。
- 値を関数に畳み、関数の引数と 4 つの呼び手からオプションを消した。
- 関数に届くテストを回した: 前に緑 12、後も緑 12。変えたテストは無し。
- オプションを述べていた関数の doc コメントを書き直した。

## 一緒に使うと良いもの

- テストの無いコードを片付ける前に、今の振る舞いをテストで留める見方。
