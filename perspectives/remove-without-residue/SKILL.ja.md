# 残りかすを残さずに消す

**芯の決まり: 物とそれを縛る物を全部消し、使っていた所を直し、消えたことを、消えたことについてのテストでなく、木に無いことで示す。**

## 落とし穴（先に読む）

- **消す。別の振る舞いに書き換えない。** 消した物を使っていた残りのコードは、それを要らなくなるように直す。代わりに新しい振る舞いを与えない。
- **消した名前が無いことだけを確かめるテストを書かない。** 木の検索が確かめになる。
- **まだ触れられている名前は消えていない。** 呼び手・テスト・文書のどれかがまだ触れていれば、消し終えていない: 残りの触れる所を消すか、振る舞いが本当に変わったのなら、その変化を示すテストを名指す。
- **名指された内に留まる。** 計画が名指した物を消す。そこから広がる消しは、新しい決めになる。

## 消し方

1. 名指された名前とファイルを消す。
2. 消した物だけを縛るテストを消す。ほかの物を縛るテストは緩めず消さない。
3. それを使っていた残りのコードを直す。
4. 自分の差分を見て、消したせいで最後の呼び手や参照を失った物（引数・変数・関数・export・import・型）を探し、それも消す。ただし公開の API には及ばない（リポジトリの中に呼び手が残らないことは、外に残らないことを示さない）。
5. **無いことを確かめる。** 消した名前ごとに、変える前の版と変えた後の木で検索する。どの触れる所（コード・テスト・注・文書・設定）も消えているか、同じ綴りの別の物だと示せる。
6. 消した振る舞いをまだ述べている文を全部書き直す。
