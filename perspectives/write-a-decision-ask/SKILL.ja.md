# 初見の読み手が答えられる決めの問いを書く

**芯の決まり: 読み手はこの run も、こちらの中の語も知らない。各項目は、その項目の文だけで決められなければならない。**

## 落とし穴（先に読む）

- **短さより事実の揃いを先にする。** 文が長くなっても、決めに要る事実を全部書く。名を出す前に、それが何で、なぜ大事かを言う。
- **中を指さない。** `<path>:<line>` の参照・記録の中の位置（ある一覧の「0 番目」など）・中のキー・項目の番号・id・記録のファイルの名を書かない。それが何かを平らな言葉で言う（ファイルと行でなく「平均を計算する関数」）。機械が確かめる参照（決める出典・訳・証拠）は、人が読む文でなく、それ用の欄に置く。
- **1 点を 1 項目に。** 同じ点がいくつかの角度（狭まる能力・方針・世の中の解き方）から出る時は、1 度だけ挙げ、ほかの角度はその 1 項目の中で触れる。

## 項目の形

この順で、各部を 1 文ずつ:

1. **題**: 何を決めるのかを、人が答えられる形で、短い 1 行で。
2. **今**: 今の姿と、それを問いにしている事実。
3. **案**: 何をするか。
4. **費用**: それに何がかかり、戻せるか、どう戻すか。
5. **勧め**: どの答えを勧めるか、とその訳。

1 つの項目がいくつかの欄に割れる時は、各部をそれを持つ欄に入れ、欄をまたいでこの順を保つ。人に聞く訳を名指す印（聞く場合のどれに当たるかなど）は中の参照ではない。先頭に置き、すぐ後に「今」を書く。
